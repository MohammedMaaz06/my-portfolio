Multi-Agent MCP Ops Assistant

Designed and built a multi-agent AI operations system where each agent (Monitoring, Incident-Triage, Notification, Deployment) runs as an independent MCP server, coordinated by a central LangGraph orchestration layer instead of hardcoded function calls.

  • • Engineered agents to pull live CPU, memory, disk, and Docker container metrics in real time, classify incident severity, detect recurring failure patterns, trigger Slack alerts, and propose automated remediation actions.
  • • Implemented human-in-the-loop approval controls so high-severity remediation actions default to dry-run mode and require explicit human sign-off before execution, reducing risk of unintended production changes.

HealOps-AI 02

Self-Healing Cloud Infrastructure Platform

Built an autonomous, self-healing ops platform that continuously monitors five simulated microservices and detects failures such as high CPU utilization, memory leaks, and crash loops in real time.

  • • Architected a LangGraph agent pipeline powered by a locally hosted LLM (Llama 3.1 via Ollama) to diagnose root causes from live metrics and event history, then automatically trigger recovery actions such as pod restarts, auto-scaling, and cache flushes.
  • • Implemented automated pre/post-fix metric comparison and Markdown incident-report generation summarizing root cause, remediation steps, and outcome, enabling fully autonomous end-to-end incident resolution.
